BIOS Checker

Open the MUOS/bios folder from your SD card to see which BIOS files are present, which are the wrong version, which have the wrong name, and which are missing. Every file is checked in your browser and nothing is uploaded.

Each file is compared against the MD5 checksums in the MustardOS core manifests. Some systems accept several regional BIOS files, so a system only needs the ones its games use, and each name must match exactly, including capital letters.
