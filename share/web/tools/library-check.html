Library Check

Open the ROMS folder from your SD card to find duplicate content and broken disc layouts. Every file is checked in your browser and nothing is uploaded.

Duplicates are matched by file name and size, and by title once region, revision and copy tags are set aside, so different regions of a game are listed together for you to decide. Disc sheets are checked for missing tracks, playlists for missing discs, and track files that no sheet uses are listed so they can be tidied up. Multi-disc games without a playlist can be given one with the Playlist Builder.

Open your ROMS folder to check it.
