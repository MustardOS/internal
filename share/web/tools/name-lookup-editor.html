Name Lookup Editor

Create and edit friendly folder names and custom content-name lookup JSON in your browser, with files opened and the finished JSON downloaded locally.

Install the result under MUOS/info/name on SD1, SD2 or USB storage. Keep a backup before replacing an existing lookup.
