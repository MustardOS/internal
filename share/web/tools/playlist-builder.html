Playlist Builder

Build a disc playlist for a multi-disc game, or a media playlist or channel list for Wasabi, in your browser, then download it ready to copy to your device.

Multi-disc game lists every disc of one game in order, so the game launches from a single entry and you can swap discs from the Disk Control menu while playing. Place the playlist beside the disc images, or beside a folder that holds them, and launch the playlist.

Media playlist plays its entries in Wasabi in order, like the episodes of a series or the tracks of an album.

Channel list becomes a list of live channels in Wasabi that you can flip through with Up and Down, using each entry's name and logo.

File paths are read relative to the folder the playlist sits in.

Leave the disc folder empty when the playlist sits beside the disc images. When the discs are kept in a folder next to the playlist, enter that folder's name and every disc path is written as folder/disc. A folder name starting with . or _ is hidden from Explore Content, so only the playlist shows.

When the discs sit beside the playlist instead, Explore Content hides each disc the playlist names, so only the playlist shows. Write each disc exactly as its file is named, and name discs with disc labels. The file|label form stops that disc being hidden. Turn on Show Hidden Content in Customisation to see every file again.
