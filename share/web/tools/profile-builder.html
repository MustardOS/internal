Profile Builder

Choose the settings you want and download them as a settings profile. Copy it to MUOS/profile and it appears under Profiles, ready to apply. To set up a freshly flashed card before its first start, save it as profile.conf on the card's ROMS partition, and the device applies it before the installer appears. A profile for new devices can also install MustardOS automatically, as described under New Device Install.

Profiles never contain wireless network details, kiosk restrictions, Danger Settings or your passcode, so they are safe to share. To connect a new card to wifi, see Network Settings Profile below.

New Device Install

These options are saved only by Download for New Devices. With automatic install enabled, a freshly flashed card skips the installer screen and prepares the ROMS partition with the file system chosen here. If the device cannot use that choice, the installer screen appears as normal and MUOS/log/profile/install_error.txt explains why.

Network Settings Profile

For your security, the builder never handles network details. To have a freshly flashed card join a wifi network from its first start, create a plain text file named wifi.conf next to profile.conf on the card's ROMS partition. Most networks only need two lines:

ssid=My Network
pass=my wifi password

To use a fixed address instead of one given by the router, add the address lines as well:

ssid=My Network
pass=my wifi password
type=static
address=192.168.0.123
subnet=24
gateway=192.168.0.1
dns=1.1.1.1

Write each setting on its own line as name=value. Lines starting with # are ignored. The file works without a profile.conf beside it.

The device reads wifi.conf once, before the installer appears, and keeps the details only in its own network settings. The file itself is removed when the card is prepared. If any line has a mistake, nothing from the file is used and MUOS/log/profile/wifi_error.txt explains what to fix, with the password left out. Network lines in any other profile are refused.
