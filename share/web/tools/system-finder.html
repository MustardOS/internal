System Finder

Explore Content does not depend on any naming convention. Your content and folders can use any names you like and can sit as many subfolders deep as you want, because the only thing MustardOS needs is a system and core assigned to the content or to a folder that holds it. See Core Assignment for how to assign them from the device.

The folder names listed below are optional shortcuts. When a folder uses one of them, MustardOS assigns the system and its default core automatically, matching without regard to case, spaces, hyphens, underscores or plus signs, so Game Boy Advance and gameboyadvance both work. Any other name works just as well once it has an assignment.

Type a system, console or folder name to see the folder names MustardOS assigns automatically, the cores that run the system, and any BIOS files it needs.
